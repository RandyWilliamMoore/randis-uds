🎮 Offline emulator

EmulatorJS, running on this computer. Nothing loads from the internet, and your game file stays here.
📂 Choose a game file, or drop it here
Pick a system first, or just choose a file and the system is guessed from its type.

Use games you own and copied yourself, or free homebrew. Zip files work too. For PlayStation, use a single .pbp or .chd file (a .cue with separate .bin files can't be picked as one). Saves and save states are kept in this view on this computer. In a game, the bar along the bottom has save states, controls, gamepad and full screen.
