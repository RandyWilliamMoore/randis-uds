RANDIS EMOJI

✨ Emoji Forge

Every Randis Emoji, including the custom icon of each app tab. Click one to copy its code (like :brain-bolt:), which shows as the picture anywhere in this app. Click ⬇ on a card for its PNG, for Discord, Slack or any app that takes custom emoji.

Make your own

Draw on a 64 × 64 grid with SVG shapes. Press Add and it is saved with this tab and shared with every page in the app.

Tip: open a built-in one, copy its SVG from the pack, then change colours.

Use it elsewhere

  • This app: type :name: in any page.
  • Any web page: the drawing code is one file, ui/randis_emoji.js. Add it with a script tag, then call RandisEmoji.observe(document.body).
  • Chat apps: download PNGs and upload them as custom emoji. They show only where you added them; phones only draw the official Unicode emoji.
