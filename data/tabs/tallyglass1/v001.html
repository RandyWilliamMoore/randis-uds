The page says which variant a visitor saw: tallyglass('exposure', 'test name', 'B'). Each visitor counts once, in the first variant they saw (anyone shown two variants is left out as "mixed"); a goal counts only if it happened after they saw the variant. Variant "A" or "control" is the baseline. Decide the visitor count with the planner first and don't stop early when it looks good.

Clicks + scroll

Opt-in per page: add data-heat="1" to the snippet. It records where clicks land (share of the page width, distance from the top, the element's tag/id/class) and how far each page view scrolled: never any text, typing or input values. In live mode the page itself is shown under the heat (scripts off, so it isn't counted again).

Tracking snippet


      
Runs only against the local engine at 127.0.0.1. Visitor ids: a daily salted hash (raw IP never stored), or a random id the page keeps (data-persist="1"). Heatmaps: add data-heat="1". Session replay: turn it on per site on the Replay page (off for every site until then). Honors Global Privacy Control and Do Not Track; visitors can call tallyglass('optout'). Custom events: tallyglass('event','name',{…}); or data-goal="name" on any button.
